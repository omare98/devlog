한국 상품을 인도네시아 고객 대신 사서 보내 주는 구매대행 쇼핑몰을 만들고 있습니다. 이 블로그에는 만들면서 정한 것과 그 이유를 적습니다.

## 지금 이런 구성입니다

- **서버:** Spring Boot 4.1(Java 25, Gradle 멀티 모듈로 관리자용과 쇼핑몰용 API 분리), MariaDB, Flyway
- **화면:** React와 TypeScript로 만든 관리자 화면과 쇼핑몰 화면
- **앱:** Capacitor로 감싼 안드로이드 하이브리드 앱
- **언어:** 화면과 오류 메시지, 메일까지 한국어·영어·중국어·인도네시아어 4개 언어

## 앞으로 쓸 이야기

- 계절마다 바뀌는 쇼핑몰 테마를 CSS 변수로 만든 방법
- 모바일 하단 탭 바를 키우며 배운 것
- 관리자 권한(역할과 계정)을 한 흐름으로 잇는 설계

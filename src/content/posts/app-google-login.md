웹에 넣은 "Google로 계속하기"는 앱 안에서는 쓸 수 없었습니다. 앱은 웹 화면을 불러오는 Capacitor 껍데기(웹뷰)인데, 구글은 앱 내장 브라우저에서 하는 로그인을 막습니다(`disallowed_useragent`). 폰이 PC의 사설 IP 주소로 접속하는 개발 환경에서는 그 주소를 승인된 원본으로 등록하는 것 자체도 거부됩니다. 그래서 앱에서는 폰의 **네이티브 구글 로그인 창**(Credential Manager)을 쓰도록 바꿨습니다.

## 서버는 그대로: 웹 클라이언트 ID를 넘기면 토큰이 같다

네이티브 로그인은 안드로이드 OAuth 클라이언트가 필요하지만, 서버가 받는 ID 토큰의 대상(audience)은 플러그인에 넘기는 클라이언트 ID가 정합니다. 플러그인에 **웹 클라이언트 ID**를 넘기면 토큰의 대상이 웹과 같아져서, 서버의 토큰 검증(서명·발급자·대상·만료·이메일 확인)을 한 줄도 안 고치고 그대로 씁니다. 신원 키(구글 고유 번호)와 "같은 이메일의 기존 회원은 비밀번호로 확인하고 연결" 규칙도 같습니다. 화면은 구글 로고가 있는 우리 버튼이 같은 콜백(토큰을 넘기는 함수)을 부르게만 했습니다. 로그인, 가입, 연결, 탈퇴 재확인이 모두 웹과 같은 흐름을 탑니다.

안드로이드 OAuth 클라이언트에는 앱의 패키지 이름과 **앱 서명 인증서의 SHA-1**을 등록합니다. 개발용(debug) 서명만 등록했고, 배포용 서명 키를 만들면 그 지문으로 클라이언트를 하나 더 만들어야 합니다. 이걸 빼먹으면 배포 앱에서만 `[28444] Developer console is not set up correctly`가 납니다.

## 플러그인 함정 하나: 플러그인 객체를 `await`하면 조용히 실패한다

푸시를 붙일 때 겪은 것과 같은 문제를 이번에도 막았습니다. Capacitor 플러그인 객체는 어떤 속성을 읽어도 메서드처럼 돌려줍니다. 플러그인을 `await`하거나 `async` 함수의 반환값으로 넘기면 JavaScript가 `then`을 확인하는데, 이것이 플러그인 메서드 호출로 바뀌어 "구현되지 않음"으로 실패합니다. `catch`로 삼키고 있었다면 앱에서만 버튼이 안 먹는 문제로 보였을 겁니다. 그래서 플러그인을 객체에 담아 쓰고, 불러오기와 초기화는 한 번만 하며, 초기화가 실패하면 다음 누름에 다시 시도하게 했습니다.

## 빌드가 막혔다: 쓰지도 않는 Apple 로그인 때문에

플러그인을 설치하고 빌드하자 `androidx.browser:browser:1.9.0`이 `compileSdk 36`과 Android Gradle 플러그인 8.9.1 이상을 요구한다며 실패했습니다. 이 라이브러리는 플러그인의 **Apple 로그인**이 쓰는 것인데, 우리는 구글만 씁니다. 플러그인은 제공자별로 포함 여부를 정할 수 있고, 설정은 `capacitor.config.ts`에 적으면 `cap sync` 때 플러그인 쪽 gradle 설정에 반영됩니다. 처음에는 프로젝트의 `gradle.properties`에 직접 적었는데 **효과가 없었습니다.** 플러그인 폴더 안의 자체 `gradle.properties`가 모든 제공자를 켜 둔 채 이쪽을 덮어쓰고 있었기 때문입니다. 정식 경로로 바꾸고도 플러그인 컴파일에서 1.9.0과 1.4.0이 부딪혀서, 이 라이브러리의 버전만 1.8.0으로 고정했습니다. Gradle 배포판을 이 PC에서 내려받을 수 없어서 AGP를 올리는 길은 택하지 않았습니다. 나중에 Apple 로그인 등을 쓰려면 이 고정을 걷고 AGP와 compileSdk를 올려야 합니다. 이 내용은 문서에 적어 두었습니다.

## 덤으로 찾은 것: 뒤로 가기가 아예 없었다

폰으로 확인하다가 뒤로 가기를 누르면 앱이 바로 닫힌다는 걸 알게 됐습니다. 문서에는 "Capacitor 기본 동작(웹 기록이 있으면 뒤로, 없으면 종료)"이라고 적어 두었는데, 소스를 읽어 보니 Capacitor 7의 안드로이드 핵심에는 뒤로 가기 처리가 없었고, 그 동작은 공식 플러그인 `@capacitor/app`에 있었습니다. 이 앱에는 그 플러그인이 없었습니다. 설치하고, 첫 화면에서는 토스트로 "벌써 나가시나요? 한 번 더 누르면 앱이 종료됩니다."를 2초간 보여 준 뒤 한 번 더 누르면 닫히게 했습니다. 틀린 문서도 고쳤습니다.

## 남긴 것

- 구글 ID 토큰의 nonce는 웹과 같이 쓰지 않았습니다(운영 전 보강).
- 배포용 서명 키의 SHA-1 등록은 키를 만들 때 합니다.
- 앱은 아직 안드로이드뿐입니다. iOS와 Apple·Facebook 로그인은 범위 밖입니다.
